# 📊 Demographic Data Analyzer

A Python data analysis application built for **freeCodeCamp's Data Analysis with Python Certification**. This project analyzes demographic data extracted from the 1994 Census database using **Pandas**.

---

## 🚀 Key Questions Answered

1. **Race Representation:** Count of people by race.
2. **Average Age of Men:** Mean age calculation for male demographics.
3. **Education Analysis:** Percentage of individuals with Bachelor's degrees.
4. **Salary vs Education:** High earners (>50K) with and without advanced degrees (Bachelors, Masters, Doctorate).
5. **Work Hours Analysis:** Salary distribution for individuals working minimum weekly hours.
6. **Global Earnings:** Country with the highest percentage of high earners (>50K).
7. **India Occupations:** Most popular occupation for high earners in India.

---

## 🛠️ Tech Stack & Requirements

- **Language:** Python 3
- **Data Library:** Pandas (`import pandas as pd`)
